# 计划：修正手机宽度区间的全屏判定

## 用户需求

用户反馈当前在浏览器响应式设备视图中，部分手机宽度区间无法进入全屏自适应，只有更大的宽度才“看起来像能用”。典型案例是 `354 × 667` 这样的手机尺寸仍然走桌面居中壳层。

## 关键决策

1. 保持桌面端默认居中展示、手机端全屏的总体策略不变。
2. 修正全屏判定逻辑，不再要求手机视口必须满足 `>= 360px` 和 `pointer: coarse` 才进入全屏。
3. 改为基于“手机尺寸几何”判定：
   - 竖屏
   - 宽度 `<= 430px`
   - 高度 `>= 640px`
4. 继续保留 `coarsePointer` 字段，暂不移除，仅不作为决定性门槛。

## 交付清单

- `ViewportProfile` 全屏判定修正
- 新增 `354 × 667` 回归测试
- 验证现有桌面模式与大手机模式不回退

## 测试计划

1. `354 × 667` -> `fullscreen + compact`
2. `1440 × 900` -> `simulator`
3. `390 × 844` -> `fullscreen + regular`
4. `pnpm test`
5. `pnpm build`
