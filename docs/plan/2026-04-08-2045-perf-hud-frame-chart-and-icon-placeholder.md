## 用户需求
- 给现有性能 HUD 增加实时帧率图，便于在手机上观察连续滑动时的抖动分布，而不只看聚合数字。
- 增加一个隔离开关：隐藏图标图片，只保留纯色占位，用来判断卡顿是否来自图标图片解码、纹理上传或过多图片绘制。

## 关键决策
1. 实时帧率图继续归属 `src/platform/perf/` 的诊断体系：采样、聚合和历史帧数据都由 `usePerformanceMonitor` 提供，HUD 只负责展示。
2. 新增的“隐藏图标图片”属于排查开关，不改变正常业务语义，因此状态放进 `perfDebugStore`，并沿用现有本地持久化和复制快照的能力。
3. 图标占位不引入随机色，避免每次刷新颜色变化；占位色通过 `app.id` 派生，保证同一个图标在每次调试里颜色稳定。
4. 这次不做资源压缩或渲染优化，只补“能看见”和“能隔离”的工具，便于下一轮基于真实数据决策。

## 实施范围
- 扩展性能快照数据结构，增加最近帧耗时历史。
- 在 Performance HUD 中新增实时帧率图。
- 在 Isolation 区域新增“隐藏图标图片”开关。
- `AppIcon` 在调试开关打开时不再渲染 `<img>`，改为纯色占位块。
- 更新单测覆盖新的 store 字段、HUD 图表和图标占位行为。

## 验收标准
- `?perf=1` 打开后，HUD 能持续显示实时帧率图，且随交互更新。
- 打开“隐藏图标图片”后，Springboard 与 Dock 图标不再加载图片，只显示稳定的纯色块，文本标签保留。
- 复制快照文本时能包含新的隔离开关状态。
- `pnpm test` 通过。
- `pnpm build` 通过。
