# 优化控制中心 (Optimize Control Center)

## 用户需求
当前控制中心的 UI 实现较差，被用户指出“和 iOS 一点也不像”。具体体现在：
- 当前所有组件（2×2 开关、亮度/音量滑块、4 个快捷 tile）都被包裹在一个单一的灰色半透明大面板（Material）中。
- 这与真实的 iOS 控制中心完全不符，iOS 的控制中心是由一个个独立的模块（卡片）组成的。

## 关键决策
为高度还原 iOS 控制中心的设计，将进行以下重构：
1. **取消全局的大容器 Material 面板**：不再使用单个卡片包裹所有内容。
2. **连接模块（Connections Widget）**：
   - 使用独立的 `Material` 容器（圆角矩形，深色毛玻璃）。
   - 内部包含 2×2 的圆形开关。
   - **去除文字标签**（iOS 控制中心的 2×2 开关不显示文字，除非长按展开）。
   - 图标背景颜色根据状态适配 iOS（飞行模式橙色、蜂窝绿色、Wi-Fi/蓝牙蓝色，关闭时为深色半透明）。
3. **滑块模块（Sliders）**：
   - 亮度滑块和音量滑块各自成为独立的 `Material` 容器，圆角胶囊状。
   - 填充色为纯白，轨道颜色为半透明。
4. **快捷操作模块（Quick Actions）**：
   - 底部 4 个快捷 tile 各自作为独立的 `Material` 块，1×1 方形，带圆角。
   - 按下或开启时，反转颜色为白底黑图标。
5. **整体布局**：
   - 各模块之间保留一致的间距（Gap，通常为 14px 或 16px）。
   - 居中对齐，分为顶部连接区、中部滑块区、底部快捷区。
