# M1-S5：App 切换 / 退出系统对齐 iOS 18 深度优化

> 日期: 2026-04-09
> milestone: M1 系统外壳 / Stage S5 (S4b 之后的优化迭代)
> 主计划索引: 本计划的完整讨论与复核记录保存在 `~/.claude/plans/distributed-hugging-seahorse.md`,本文件为落库简化版

## 用户需求

用户明确要求: **深度优化当前 App 切换与退出模块,与 iOS 18 对齐,使动效与用户体验一致,操作符合直觉、易于理解**。

具体痛点盘点 (基于当前代码现状):

1. **手势视觉滞后**: Switcher 预览要到 `progress=0.18` 才出现 (`Device.tsx:80`, `AppSwitcher.tsx:24-26`),前段手势无反馈,用户无法感知"正在进入 Switcher"。
2. **卡片拖拽手感失真**: 上拉卡片为线性位移,无 rubberBand 阻尼;`useState(dragY)` 违反 `src/CLAUDE.md` 踩坑 #3 (瞬态数据不经 React state)。
3. **退出动效脱钩释放速度**: `finishCardDismiss` / `commitHomeGesture` 都用固定 `spring.smooth`,忽略 vy。现有工具 `springFromVelocity` 在这两个模块未被使用。
4. **HomeBar 手势取消用 CSS transition**: 与系统其它 spring 动效风格不一致,`lift = deltaY * 0.22` 是线性而非缓出。
5. **Switcher 内部缺少层次感**: 卡片入场无 stagger,preview 态没有视觉区分。
6. **从 Switcher 激活 app 没有 morph**: 现在直接 scale 0.78→1.0,没有从卡片真实位置 morph 到全屏。
7. **潜在 bug**: `AppHost` 的 dismissed-app exit 在 card-swipe 场景会错误地飞回 switcher 卡片位置;`clearDismissedApp` 在 AppSwitcher / AppHost 两处 onAnimationComplete 各调用一次,存在 race。

## 关键决策

1. **不重写状态机,只扩展字段 + 接入物理工具**: 保留 `appRuntimeStore` 的三源合一不变量 (AGENTS.md 约束),只新增 `switcherCardOrigin` / `dismissReason` 字段与 `activateAppFromCard` action;现有 action 保持行为一致。
2. **SwitcherCard 改用 motion value (命令式)**: 不使用 `animate` + `style` 混合 (motion v12 不支持),而是 `style={{ y: mv }}` 排他绑定 + `useEffect` 里命令式 `animate(mv, target, springFromVelocity(...))` 推 fling。
3. **释放速度全链路**: `finishCardDismiss` / `commitHomeGesture` 返回 `{ committed, velocity }`,交给 UI 层用 `springFromVelocity` 配置退出动画。
4. **rubberBand 传 cardHeight (不是 cardHeight × 1.5)**: `rubberBand` 内部 0.55 系数已定义渐近极限,不需要外部放大。
5. **switcherCardOrigin 独立于 appOrigin**: 避免污染 `appOrigin` 的"icon rect"语义;`AppHost` 的 initialAnimation 分支按 `transitionSource + origin 可用性` 路由到 icon morph / card morph / fallback 三种。
6. **Preview 去饱和应用在 wallpaper 层**: 不在 AppSwitcher 容器加 `filter: saturate`,改为 Device 层新增 motion-value 驱动的 saturate overlay (受 `disableDesktopFilter` 控制),避免整子树 paint 成本和 commit 瞬间的 snap 闪烁。
7. **HomeIndicator bar 用 scaleX 而非 width 形变**: GPU 友好,不走 paint。
8. **dismissReason 区分退出路径**: `'card'` → `y=-viewportHeight, scale=0.6, opacity=0` (飞出顶部),`'home'` → 保持现状 `y=844, scale=0.3` (向下回桌面)。
9. **clearDismissedApp 统一由 AppHost 负责**: 移除 AppSwitcher 中的重复调用,消除 race。
10. **gestureIntent 以 selector 形式导出**: 而不是存储字段,避免 60fps 写 store 字段触发订阅者 fan-out。
11. **prefers-reduced-motion 不纳入本期**: 留到无障碍专项统一处理,本期聚焦动效对齐。
12. **不引入新依赖**: 全部使用既有 `motion/react` (含命令式 `animate` 函数) + 既有 gesture / design-token 工具。

## 交付清单 (按执行顺序)

### P0 物理与释放速度 (先落,风险最小)
- **P0a**: SwitcherCard `useState(dragY)` → `useMotionValue(0)` + `useTransform`
- **P0b**: 接入 `rubberBand(rawDelta, cardHeight)`;修复 jsdom 测试夹具 `getBoundingClientRect().height=0` 问题
- **P0c**: `finishCardDismiss` / `commitHomeGesture` 返回 velocity;SwitcherCard 命令式 `animate(mv, -vh, springFromVelocity(...))`;AppHost 的 exit 动画接入 velocity

### P1 视觉反馈同步
- **P1a**: `Device.tsx:80` 阈值 0.18→0.05,`AppSwitcher.tsx:24-26` 同步;Device 新增 wallpaper saturate overlay (motion-value 驱动 `useTransform(gestureProgress, [0, 0.6, 1], [1, 0.7, 1])`)
- **P1b**: `useGestureIntent` 派生 selector
- **P1c**: HomeIndicator 升级到 motion value (y / opacity / scaleX),`easeOutQuad` 替换线性 lift,snap-back 用命令式 spring
- **P1d**: SwitcherCard preview 态用 `opacity: 0.55` 区分 (GPU 友好)

### P2 层次感与 morph
- **P2a**: `appRuntimeStore` 新增 `switcherCardOrigin` + `activateAppFromCard`
- **P2b**: `AppHost.initialAnimation` 新增 `transitionSource === 'switcher' && switcherCardOrigin` morph 分支
- **P2c**: SwitcherCard 入场 stagger (`index * 0.04`) + 选中状态 boxShadow 加重
- **P2d**: `dismissReason` 区分 home/card 退出;`AppHost` 按 reason 切换 exit 目标;移除 AppSwitcher 重复的 `clearDismissedApp` 调用

### P3 测试与文档

- 新建 `src/shell/AppSwitcher/AGENTS.md`

## 验收标准

1. 从 Settings 慢速上滑 → Switcher 在 progress≈0.05 就淡入,进度连续
2. 从 Settings 上滑松开 → 回桌面动画带释放速度,不再是固定 spring
3. 在 Switcher 中上拖卡片 → 阻尼明显,物理回弹自然
4. 在 Switcher 中上甩卡片 → 向屏幕顶部飞出 (修复 latent bug),速度与手指一致
5. 在 Switcher 中点击非选中卡片 → 从该卡片真实位置 morph 到全屏
6. HomeIndicator bar 的取消 snap-back 用 spring 弹回
7. preview 阶段 wallpaper 去饱和 + 未选卡片半透明,commit 时平滑恢复无闪烁
8. 现有 `pnpm test` / `pnpm build` 全绿,无回归
9. 潜在 bug (card 退出方向、race) 同步修复

## Non-goals

- 不重写 `appRuntimeStore` 的状态机
- 不改变 Switcher scroll snap (保持浏览器原生)
- 不引入触觉反馈
- 不实现"摁住卡片显示删除按钮"
- 不调整 ControlCenter / NotificationCenter 手势
- prefers-reduced-motion 留到无障碍专项
