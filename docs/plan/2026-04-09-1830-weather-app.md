# 天气 App — 1:1 复刻 iOS 18 Weather

## 需求
复刻 iOS 18 天气 App，获取用户当地实时天气数据进行渲染。需要还原 iOS Weather 的完整视觉层次：动态渐变背景、毛玻璃卡片、24小时/10天预报、8个天气模块。

## 关键决策

1. **天气 API**: Open-Meteo（免费、无需 API key、支持全球数据）
2. **定位**: `navigator.geolocation` 获取经纬度 + Nominatim 反向地理编码获取城市名
3. **降级策略**: 定位失败时使用北京坐标（39.90, 116.40）
4. **渐变背景**: 根据 WMO 天气代码 + `is_day` 字段动态计算 CSS linear-gradient
5. **毛玻璃卡片**: `<Material variant="thin">` + 覆盖 backgroundColor 为 `rgba(255,255,255,0.15)` 实现更透明的 iOS Weather 风格
6. **天气图标**: 基于 Lucide 开源 SVG 路径，stroke 风格，符合 SF Symbol 规范
7. **温度条**: 10天全局温度范围映射，CSS gradient 从冷色（蓝）到暖色（红）

## 实现范围

### Sections
| 区域 | 说明 |
|------|------|
| Header | 城市名(34px/600)、温度(96px/200)、天气状况(20px)、最高最低 |
| 24小时预报 | 毛玻璃卡片，顶部摘要文字，分割线，横向滚动25小时，每列：时间/图标/温度 |
| 10天预报 | 毛玻璃卡片，日期/图标/低温/彩色温度条/高温 |
| UV 紫外线 | 数值 + 等级描述 + 防护建议 |
| 日落 | 日落时间 + SVG太阳弧线可视化 + 日出时间 |
| 风 | 风向 + 风速 + 阵风 |
| 降水 | 概率百分比 |
| 体感温度 | 体感值 + 与实际温度对比描述 |
| 湿度 | 百分比 + 露点温度 |
| 能见度 | 公里数 + 描述 |
| 气压 | 百帕值 + 趋势描述 |

## Open-Meteo API 参数

```
current: temperature_2m, relative_humidity_2m, apparent_temperature, weather_code,
         wind_speed_10m, wind_direction_10m, wind_gusts_10m, surface_pressure, is_day
hourly:  temperature_2m, weather_code, precipitation_probability, is_day,
         dew_point_2m, visibility, uv_index
daily:   weather_code, temperature_2m_max, temperature_2m_min, sunrise, sunset,
         uv_index_max, precipitation_probability_max
```
