# 天气 App UI 优化 — 动效、SVG、细节打磨

## 需求
在现有天气 App 基础上优化 UI 细节、改进 SVG 图标质量、增加动态效果，使其更接近 iOS 18 Weather 的精致体验。

## 关键决策

1. **动效框架**: 使用已有的 `motion/react` + design-tokens/motion 中的 spring 预设
2. **渐进增强**: 动效为锦上添花，不影响数据渲染的核心流程
3. **性能优先**: 动画使用 CSS transform/opacity，避免触发 layout

## 优化清单

### 1. Loading 骨架屏
- iOS 风格 shimmer 动画替代纯文字 "正在获取天气数据..."
- 模拟 Header + 逐时 + 逐日 + 模块卡片的布局骨架

### 2. SVG 天气图标增强
- 太阳: 添加暖色填充 + 光芒动画（CSS rotate）
- 月亮: 添加微光 glow 效果
- 雨滴: 改为斜线 + 动画降落效果
- 雪花: 用六角形替代圆点
- 闪电: 添加黄色填充
- 整体提升辨识度和 iOS 一致性

### 3. 逐时预报优化
- 降水概率 > 0 时显示蓝色百分比（iOS 特色）
- 左右边缘添加渐变遮罩（scroll fade）

### 4. 10 天预报优化
- 当前温度在温度条上用白色圆点标记
- 今天行高亮处理

### 5. 模块卡片入场动画
- stagger 渐入效果（从下向上 fade + translate）
- 滚动触发，进入视口时播放

### 6. 日落模块 SVG 改进
- 太阳弧线添加渐变色（日出黄→日落橙）
- 太阳圆点添加 glow 光晕
- 地平线虚线更精致

### 7. 风模块指南针改进
- 更精致的圆环 + 刻度线
- 箭头改为三角指示器

### 8. 气压仪表盘改进
- 圆弧添加渐变（低→标准→高）
- 指针改为细长三角形 + 圆心

### 9. Header 动效
- 温度数字 scale 入场
- 天气描述文字 fade 入场

## 文件改动
| 文件 | 改动 |
|------|------|
| `WeatherApp.tsx` | 骨架屏、入场动画、细节调整 |
| `WeatherIcon.tsx` | SVG 重绘、填充色、动画 class |
| `weatherConfig.ts` | 无改动 |
| `useWeatherData.ts` | 无改动 |
