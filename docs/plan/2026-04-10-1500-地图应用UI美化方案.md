# 地图应用UI美化方案

**日期**: 2026-04-10
**状态**: 计划中

## 用户需求
- 优化地图应用，使其更美观
- 系统 UI 需高仿 iOS Maps，提升整体视觉体验和交互细节

## 关键设计决策 (方案内容)

### 1. 地图底图优化 (Map Tiles)
- **瓦片源调整**：将瓦片源从 `light_all` (灰白为主) 替换为 CartoDB `voyager`。Voyager 带有更多自然色彩（绿色植被、蓝色水系）和更清晰的道路层级，大幅贴近 Apple Maps 的生动观感。

### 2. 标记点与定位点 (Markers & Location Dot)
- **搜索结果标记点**：由目前的系统蓝 (Blue) 修改为 Apple Maps 经典的亮红 (Red `#FF3B30`) 气球样式，重绘 SVG，增加更柔和的投影 (DropShadow) 以体现立体感。
- **当前定位点**：给蓝色定位点增加外扩雷达波纹动画 (Pulsing Radar Effect)，增强动态生命力和沉浸感。

### 3. 底部面板与搜索栏 (Bottom Sheet & Search Bar)
- **材质与阴影**：强化底部面板的 Material 毛玻璃效果，顶部增加更细腻的边框线 (`border-top: 1px solid rgba(255,255,255,0.2)`) 和扩散阴影 (`box-shadow: 0 -4px 24px rgba(0,0,0,0.08)`)，模拟 iOS 的卡片浮动感。
- **拖拽手柄**：尺寸保持经典的 `36px * 5px`，颜色调整为更柔和的系统分割线颜色 (`var(--color-tertiaryLabel)`)。
- **搜索栏 UI**：搜索框增加聚焦态的微动画，背景色调优，保证在深浅色模式下都能完美融合。

### 4. 分类导航图标 (Explore Categories)
- **形状调整**：将分类图标背景从圆角矩形 (`borderRadius: 14`) 修改为 iOS Maps 标志性的正圆形 (`borderRadius: '50%'`)。
- **排版优化**：微调 2x4 Grid 的间距和文字大小 (11px -> 12px 细体)，使页面呼吸感更强。

### 5. 地图悬浮控件 (Map Controls)
- **布局增强**：在右上角的悬浮控件组中，增加一个“地图图层 (Map Layers)”图标，与原有的“定位 (Locate)”按钮组合成药丸/圆角矩形结构，让界面不再单调。
- **视觉风格**：按钮使用 `variant="chrome"` 结合 `.5px` 的边框线，高仿 iOS 15+ 右侧悬浮组件。

## 实施步骤
1.  **更新底图配置**：修改 `mapConfig.ts` 中的 `TILE_URL` 为 Voyager 源。
2.  **重绘 Marker 动画**：修改 `MapView.tsx`，将 `PIN_SVG` 改为红色并优化轮廓；给 `LOCATION_DOT_SVG` 植入 CSS 呼吸动画。
3.  **重构分类视图**：修改 `ExploreCategories.tsx` 调整图标容器为圆形。
4.  **丰富悬浮控件**：修改 `MapControls.tsx`，加入图层按钮并优化排版。
5.  **精修底部面板**：修改 `MapsApp.tsx` 和 `SearchBar.tsx` 提升毛玻璃边缘、阴影和手柄的质感。
