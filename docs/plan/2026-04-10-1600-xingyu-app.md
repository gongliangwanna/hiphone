# 星语 App — 原创可爱虚拟偶像聊天软件

**日期**: 2026-04-10
**状态**: Demo 已完成

## 用户需求
设计一个全新的可爱聊天软件，面向 18~24 岁女生，核心场景是与虚拟偶像聊天。
- 功能：单聊、群聊、朋友圈、通讯录
- 核心：可爱风格 + 丰富动效
- 不参考现有软件，完全原创设计

## 设计决策

### 品牌: "星语" (Star Whisper)
- 星 = 明星/偶像，语 = 私密聊天
- 梦幻星空 + 粉彩泡泡的视觉语言

### 色彩系统
- Primary: 粉色渐变 #FF9A9E → #FECFEF
- Secondary: 薰衣草渐变 #A18CD1 → #FBC2EB
- Accent: 薄荷 #A8EDEA, 天空 #8EC5FC, 金色 #F6D365
- 背景: 奶粉 #FFF5F7
- 文字: 柔暗紫 #2D1B33 (非纯黑)
- 阴影: 粉色调 rgba(255,154,158,0.12)

### 动效体系 (核心差异化)
- Tab 切换: bouncy spring + scale 效果
- 消息出现: opacity + y + scale 弹入
- 头像: 渐变光圈 + 在线呼吸灯 + 浮动动画
- 点赞: 双击弹出大爱心
- 输入框发送按钮: scale 弹入/弹出
- 背景: 浮动的 ♡ ✦ ✧ 装饰粒子
