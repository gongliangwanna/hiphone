# 可爱信 App — 原创可爱虚拟偶像聊天软件

**日期**: 2026-04-10
**状态**: Demo 已完成

## 用户需求
设计一个全新的可爱聊天软件，面向 18~24 岁女生，核心场景是与虚拟偶像聊天。
- 功能：单聊、群聊、朋友圈、通讯录
- 核心：可爱风格 + 丰富动效
- 不参考现有软件，完全原创设计

## 设计决策

### 品牌: "可爱信" (Cute Letter)
- 可爱 = 目标受众和视觉风格
- 信 = 传递温暖和心意
- 梦幻马卡龙 + 温暖克制的视觉语言

### 色彩系统
- Primary: 樱花粉渐变 #FFAEC9 → #FFC1CC
- Secondary: 浅粉渐变 #FFD1DC → #FFE4E1
- Accent: 薄荷 #B4E4D9, 天空 #BFE4FF, 闪亮金 #FFD700
- 背景: 奶粉 #FFF8FA
- 文字: 暖褐灰 #4A3B42
- 阴影: 中性极淡阴影

### 动效体系 (核心差异化)
- Tab 切换: bouncy spring + scale 效果
- 消息出现: opacity + y + scale 弹入
- 头像: 渐变光圈 + 在线呼吸灯 + 浮动动画
- 点赞: 双击弹出大爱心
- 输入框发送按钮: scale 弹入/弹出
- 背景: 浮动的 ♡ ✦ ✧ 装饰粒子
