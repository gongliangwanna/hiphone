# 地图 App 开发计划

**日期**: 2026-04-10
**状态**: 进行中

## 用户需求
- 添加新的地图 app，与 iOS 地图 app 保持一致
- 用心设计，高还原 iOS 地图的视觉与交互

## 关键设计决策

### 地图引擎
- 使用 **Leaflet + react-leaflet** + OpenStreetMap 瓦片
- 免费开源，无需 API key，支持交互缩放/拖拽/标记
- 瓦片风格选用浅色系，接近 Apple Maps 观感

### UI 架构（高仿 iOS Maps）
1. **全屏地图** — 地图铺满整个屏幕，无 NavBar
2. **浮动搜索栏** — 顶部圆角搜索框，glass material 毛玻璃效果
3. **底部面板 (Bottom Sheet)** — 可拖拽的半屏面板
   - 默认折叠态：显示搜索栏 + 探索分类
   - 展开态：搜索结果 / 地点详情
4. **地图控件** — 右侧浮动：定位按钮、指南针、3D切换
5. **探索分类** — 餐饮、加油站、咖啡、购物等快捷分类
6. **地点详情** — 选中地点后底部面板展示详情卡片
7. **搜索功能** — 使用 Nominatim（OSM 免费地理编码 API）

### 状态管理
- `mapsNavStore.ts` — 管理面板状态（collapsed/search/detail）
- 无需持久化（地图每次打开回到默认视图）
- 支持 `wasAppKilled()` 重置

### 视觉风格
- 地图控件使用 Material glass 效果
- 搜索栏圆角 12px，内部输入框
- 底部面板拖拽手柄 + 圆角顶部
- 分类图标使用 SF Symbol 风格 SVG
- 配色跟随 iOS 系统蓝/灰色调

## 文件结构
```
src/apps/Maps/
├── MapsApp.tsx          — 主入口
├── mapsStore.ts         — 面板与搜索状态
├── MapView.tsx          — Leaflet 地图封装
├── SearchBar.tsx        — 浮动搜索栏
├── BottomSheet.tsx      — iOS 风格底部面板
├── ExploreCategories.tsx — 探索分类入口
├── PlaceDetail.tsx      — 地点详情卡片
├── MapControls.tsx      — 定位/指南针/缩放控件
├── searchService.ts     — Nominatim 搜索封装
└── mapConfig.ts         — 地图配置常量
```

## 集成点
- `AppScene.tsx` 添加 `if (appId === 'maps') return <MapsApp />`
- `apps.data.ts` 已有 maps 条目（id: 'maps', icon: maps.jpg）
