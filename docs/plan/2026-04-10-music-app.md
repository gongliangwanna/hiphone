# 音乐 App — 一比一复刻 iOS Apple Music

## 日期
2026-04-10

## 用户需求
一比一复刻 iOS Apple Music 应用，包含完整的 Tab 导航、资料库浏览、Now Playing 播放器界面。

## 关键决策

### 1. Tab 结构
采用 iOS 18 Music 的 4 Tab 布局：
- **现在就听 (Home)** — 个性化推荐首页
- **浏览 (Browse)** — 分类浏览、编辑精选
- **广播 (Radio)** — 电台列表
- **资料库 (Library)** — 用户音乐库

### 2. 播放器架构
- **MiniPlayer**: 悬浮在 TabBar 上方的迷你播放条，显示当前歌曲信息和控制按钮
- **NowPlaying**: 全屏播放视图，从 MiniPlayer 展开，包含大专辑封面、进度条、完整控制
- 播放状态通过 Zustand store 全局管理，persist 到 localStorage

### 3. 数据层
使用静态 mock 数据（歌曲、专辑、播放列表），不接入真实音频播放。
播放状态（当前歌曲、播放/暂停、进度、队列）存储在 musicDataStore 中。

### 4. 视觉风格
- 暗色主题为主（#000000 背景），Apple Music 红色强调色 (#FC3C44)
- NowPlaying 背景使用专辑封面提取的自适应渐变模糊效果
- 毛玻璃 TabBar 和 MiniPlayer
- SF Symbol 风格图标

### 5. 导航架构
- musicStore: activeTab + page (null=tab根, 'now-playing'=全屏播放器, 'album-detail'等)
- 遵循项目既有的 AnimatePresence + motion slide 动画模式
- kill 检测 + reset 模式

## 文件结构
```
src/apps/Music/
├── MusicApp.tsx          # 主入口，Tab + 页面路由编排
├── musicStore.ts         # 导航状态 (activeTab, page, activeSongId)
├── musicDataStore.ts     # 播放状态 + mock 数据 (persist)
├── data.ts               # 静态 mock 数据（歌曲、专辑、播放列表、电台）
├── TabBar.tsx            # 底部 Tab 栏
├── MiniPlayer.tsx        # 迷你播放条
├── NowPlaying.tsx        # 全屏播放视图
├── tabs/
│   ├── HomeTab.tsx       # 现在就听
│   ├── BrowseTab.tsx     # 浏览
│   ├── RadioTab.tsx      # 广播
│   └── LibraryTab.tsx    # 资料库
└── pages/
    └── AlbumDetail.tsx   # 专辑详情页
```

## 里程碑
1. **M1**: 基础框架 — store + TabBar + 空 Tab 页面 + 注册
2. **M2**: Library + Home Tab 内容填充
3. **M3**: Browse + Radio Tab
4. **M4**: MiniPlayer + NowPlaying 全屏播放器
5. **M5**: 构建验证 + 部署
