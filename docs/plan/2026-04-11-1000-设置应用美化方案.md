# 设置应用 (Settings) 高级 iOS 风格美化方案

## 用户需求
- 优化现有的“设置”App 界面，解决“有点丑”的问题，使其在视觉和交互上更加美观。
- 深度还原 iOS 18 风格的设置应用界面（包括卡片布局、列表间距、标题栏样式、统一的边框、图标风格等）。

## 关键决策

### 1. 系统组件级升级 (system/List)
为了避免在 `SettingsHome.tsx` 中写大量内联样式和重复造轮子，我们先对底层的 `system/List` 进行功能增强，使其支持 iOS 风格设置项的标准布局：
- **ListSection 升级**：增加 `title` 和 `footer` 属性，支持 iOS 风格的段落头部文字（全大写或小号灰色）和尾部文字说明。
- **ListRow 升级**：
  - 支持 `icon`（图标内容）和 `iconColor`（图标背景色），实现标准带圆角底色的设置图标（如 iOS 设置中的蓝牙、无线局域网图标）。
  - 支持 `rightContent` 自定义插槽（用于放入 `Toggle` 开关或带有缩略图的预览内容）。
  - **精细化分割线（Inset Separator）**：iOS 的列表分割线通常不会贯穿整个屏幕宽度，而是从文本的左边缘开始。我们将优化 `isLast` 及底边框，使其在有图标时，底边框对齐文字而不是跨过图标。

### 2. 设置首页重构 (SettingsHome)
- **Apple ID 风格的个人信息卡片**：顶部个人名片使用更大的点击区域、圆角和合理的内边距，完全对齐 iOS 的账号卡片样式（头像大尺寸居左，主副标题紧凑堆叠）。
- **统一列表模块**：将原有的手动 `SettingsIconRow` 替换为增强后的 `ListSection` + `ListRow`，移除手写冗余代码。
- **增加模块间距（Section Gap）**：将各功能模块按 iOS 标准间距进行分组，比如分为“个人中心”、“虚拟连接（AI等）”、“系统设置（关于、壁纸等）”。

### 3. 设置子页面重构
所有的子页面需要统一使用增强版 `List` 结构，丢弃页面内部硬编码的分割线或卡片背景。
- **AboutPage (关于本机)**：使用纯列表展示，配合 `ListSection` 组织各项属性。
- **WallpaperPage (壁纸)**：优化展示比例。
- **DisplayPage (显示与亮度)** 等等其他页面统一更换底层 UI，并确保与系统主题色（黑夜/白天）和谐。

### 4. 颜色与排版优化
- 统一使用 `var(--color-secondarySystemBackground)` 作为大背景。
- 统一使用 `var(--color-tertiarySystemBackground)` 作为卡片（ListSection）背景。
- 分割线使用 `var(--color-separator)`。
- 文字尺寸严格遵循 `var(--font-size-body)` / `var(--font-size-subheadline)`。

3. 重构其他关联的子页面（`AboutPage.tsx`, `DisplayPage.tsx` 等）。
4. 跑测试并进行视觉走查。
