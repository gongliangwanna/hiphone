# 星语 App — 个人资料头像与封面自定义

## 日期
2026-04-11

## 用户需求
1. 个人封面（ProfileTab 顶部）需要设置一张好看的图片，而非纯渐变色
2. 在"我的"设置中可以修改头像
3. 在"我的"设置中可以修改封面图

## 关键决策

### 数据模型
- `UserSettings` 新增 `avatarUrl: string` 和 `coverUrl: string`
- 默认头像保持 `ME.avatar`（pravatar），默认封面用一张好看的 picsum 风景图
- 数据持久化到 localStorage（已有 persist middleware）

### 图片选择方式
- 由于是模拟手机，提供预设图片网格供用户选择（类似相册选图）
- 预设头像：8 张 pravatar 风格头像
- 预设封面：8 张 picsum 风景/美图
- 点击头像/封面区域弹出选择面板

### UI 变更
1. **ProfileTab**：封面从纯渐变改为图片 + 底部渐变叠加，头像从 `ME.avatar` 改为 `settings.avatarUrl`
2. **Settings**：头像区域可点击，新增封面选择区域，均展示当前选中 + 更换按钮

## 涉及文件
- `src/apps/XingYu/xingYuDataStore.ts` — UserSettings 接口扩展
- `src/apps/XingYu/data.ts` — 预设图片数组
- `src/apps/XingYu/tabs/ProfileTab.tsx` — 封面图片 + 头像读取
- `src/apps/XingYu/pages/Settings.tsx` — 头像/封面选择器 UI
