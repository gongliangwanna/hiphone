# 壁纸设置页优化

## 日期
2026-04-13

## 用户需求
优化设置-壁纸页面，使其：
1. 可以**添加**自定义壁纸（已有功能，保留）
2. 可以**切换**壁纸（点击即选中，当前UX不够直观）
3. 可以看到**默认系统壁纸**（已有，但展示不够突出）

## 现状问题
1. **预览区过大** — 当前壁纸预览占据完整 9:16 比例，用户需大量滚动才能看到壁纸选项
2. **系统壁纸标题不直观** — "选取新壁纸" 暗示只能选新的，不像"系统默认壁纸"
3. **大量 inline style** — 不符合 Tailwind utility 优先规范
4. **缺少分类展示** — iOS 原生壁纸页面有分类概念，当前只是平铺

## 关键决策

### 1. 布局重设计
- 顶部：紧凑手机形状预览卡（缩小至约 40% 宽度居中），展示当前壁纸效果
- 中间："系统壁纸" section，3列网格展示7张默认壁纸
- 底部："我的壁纸" section，上传按钮 + 自定义壁纸网格，可删除

### 2. 交互增强
- 选中壁纸有蓝色边框 + 勾选标记（更明显的选中态）
- 点击即切换，无需额外确认

### 3. 样式迁移
- inline style → Tailwind utility classes
- 动画相关保留 inline style（符合规范例外）

### 4. 不做的事
- 不增加壁纸分类/收藏功能（超出需求范围）
- 不做壁纸预览全屏模式
