# 聊天中分享卡片（备忘录、音乐）UI 优化设计

## 用户需求
用户反馈：备忘录分享的卡片，以及音乐（应用）分享的卡片长得太丑了，需要重新设计。

## 关键决策

在 iOS (iMessage) 中，分享的 Rich Link 卡片通常具备以下特点：
1. **统一的大圆角**：不再使用对话气泡那种一侧直角的样式，而是统一的 `18px` 或 `20px` 圆角，让它看起来像一个独立的分享卡片。
2. **更宽的尺寸**：从原本的 `220px` 增加到 `250px` 或 `260px`，避免文字过于拥挤。
3. **精致的布局与阴影**：
   - 增加更柔和的背景和边框 (`rgba(0,0,0,0.05)`)。
   - 分割线更细致。
4. **备忘录卡片内部设计**：
   - 摒弃左右布局和简陋的 Lucide 图标。
   - 改为真正的 iOS “富文本预览卡片”结构。
   - 顶部 Header 包含极淡的黄色渐变背景、真实的 iOS 备忘录 App Icon (`notes.jpg`) 和暗黄色字体的“备忘录”标识。
   - 下方是加粗的标题和多达 3 行的文本预览，营造出“截取了一段真实纸张”的视觉体验。
5. **音乐卡片内部设计**：
   - 摒弃老旧的小缩略图列表式设计。
   - 改为“上图下文”的现代大卡片结构。
   - 顶部是完整的 1:1 比例专辑封面铺满宽度，并在中心悬浮一个毛玻璃材质的播放按钮 (`Play`)，视觉冲击力极强。
   - 底部是白底区域，左侧展示加粗歌名和灰色歌手名，右侧点缀真实的 Apple Music App Icon (`music.jpg`)。
6. **交互反馈**：点击时应有轻微的按压变暗反馈。

## 实施步骤
1. 修改 `src/apps/XingYu/pages/ChatDetail.tsx`。
2. 找到 `msg.noteRef` 和 `msg.songRef` 的渲染逻辑。
3. 重构这两个卡片的 DOM 结构与 CSS 样式。
4. 使用统一的 `borderRadius: 18`。
5. 去除对话气泡特有的 `borderTopRightRadius: isMine ? 4 : 12` 这种不对称圆角，改为全圆角。
6. 调整内外边距、字体大小和颜色。
