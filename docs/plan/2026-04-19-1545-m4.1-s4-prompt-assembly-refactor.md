# M4.1 S4 — promptAssembly Refactor (role alternation + name prefix)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current "first-person labeled system block" render with "role alternation + speaker-name prefix". Switch `promptAssembly`'s data source from xingYuDataStore `HistoryMessage[]` to `characterMemoryStore` `MemoryEntry[]`. Delete the now-obsolete `buildLabeledHistory` + `messageToContent` logic.

**Architecture:**
- New internal function `renderMemoryToChatMessages(entries, ctx)` maps MemoryEntry[] → ChatMessage[]. assistant entries pass content through untouched (raw JSON preserved); user entries prepend `<speakerName>：`; system entries (compressed summary) pass through.
- `assemblePrompt` signature changes: the `history: HistoryMessage[]` + `characterSenderId` + `senderNames` + `summary` + `summaryUpToTimestamp` inputs are replaced by `memoryEntries: readonly MemoryEntry[]` + `currentCharId` + `charactersById`. Summary handling becomes implicit (a `role:'system', compressed:true` entry naturally renders as a `system` role message).
- `buildLabeledHistory` and `messageToContent` are deleted. All three callers (`xingYuDataStore.scheduleAICharacterReply`, `heartbeatAgent.runHeartbeat`, `aiChatEngine.runAIChat`) update their `assemblePrompt` invocation.
- `collectCharacterHistory` is NOT deleted in this stage — it's deleted in S5. Here we just stop calling it; we pass `memoryEntries` directly.

**Tech Stack:** TypeScript, Vitest. Depends on S1 (characterMemoryStore) and S3 (memoryStore already populated).

```typescript
import type { MemoryEntry } from './characterMemoryStore';

export interface MemoryRenderContext {
  currentCharId: string;
  charactersById: Map<string, { id: string; name: string }>;
  personaName: string;
}

export function renderMemoryToChatMessages(
  entries: readonly MemoryEntry[],
  ctx: MemoryRenderContext,
): ChatMessage[] {
  const out: ChatMessage[] = [];
  for (const e of entries) {
    if (e.role === 'system') {
      out.push({ role: 'system', content: e.content });
      continue;
    }
    if (e.role === 'assistant') {
      out.push({ role: 'assistant', content: e.content });
      continue;
    }
    // role === 'user' — prepend speaker name
    const name = resolveSpeakerName(e.speakerId, ctx);
    out.push({ role: 'user', content: `${name}：${e.content}` });
  }
  return out;
}

function resolveSpeakerName(
  speakerId: string,
  ctx: MemoryRenderContext,
): string {
  if (speakerId === 'me') return ctx.personaName;
  if (speakerId.startsWith('char-')) {
    const charId = speakerId.slice('char-'.length);
    return ctx.charactersById.get(charId)?.name ?? speakerId;
  }
  return speakerId;
}
```

```typescript
function trimMemoryToFit(
  entries: readonly MemoryEntry[],
  tokenBudget: number,
  keepRecent: number,
): readonly MemoryEntry[] {
  if (entries.length === 0) return entries;

  // Always keep the N most recent entries.
  const recentStart = Math.max(0, entries.length - keepRecent);

  // Budget the full list first; if it fits, return as-is.
  let tokens = 0;
  for (const e of entries) tokens += estimateTokens(e.content) + 6 /* role overhead */;
  if (tokens <= tokenBudget) return entries;

  // Trim from the oldest non-recent.
  let trimStart = 0;
  while (tokens > tokenBudget && trimStart < recentStart) {
    tokens -= estimateTokens(entries[trimStart]!.content) + 6;
    trimStart++;
  }
  return entries.slice(trimStart);
}
```

At the trigger-user-message extraction site (where `buildLabeledHistory` previously did this), remove the "last non-self → user role" extraction — role alternation already handles this naturally. If `chatMessages[chatMessages.length - 1]` happens to be `role:'assistant'`, that's handled at call sites (XingYu / heartbeat will have appended a trigger user message to `memoryEntries` before calling `assemblePrompt`, so the last role will naturally be `user`).
