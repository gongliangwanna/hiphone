# M4.1 S10 — XingYu Rich Messages Migration to Session

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ensure XingYu's rich message actions (image / sticker / forward_card / note / song) properly trigger AI replies via the new session path from S9. Most of this work is already done by S3 (`_appendMessage` at the user-input side) and S9's unified `scheduleAICharacterReply` — this stage primarily verifies each path end-to-end with explicit tests.

**Architecture:** No new code paths. Each of `sendImageMessage` / `sendStickerMessage` / `sendForwardCardMessage` / `sendNoteMessage` / `sendSongMessage` already routes through `_appendMessage` (S3) + triggers `scheduleAICharacterReply` (S9's rewrite). This stage writes one test per variant to prove the end-to-end flow: (user side gets to memoryStore via `_appendMessage`'s `buildMemoryEntry`) + (AI reply arrives via session + bubble delivery).

**Tech Stack:** TypeScript, Vitest.

```typescript
// src/apps/XingYu/__tests__/xingyu-image-trigger.test.ts
import { describe, it, expect, vi, beforeEach } from 'vitest';
import { useXYData } from '../xingYuDataStore';
import { useCharacterStore } from '@/platform/stores/characterStore';
import { useCharacterMemory } from '@/platform/ai/characterMemoryStore';
import { useAIConfigStore } from '@/platform/stores/aiConfigStore';
import * as chatCompleteMod from '@/platform/ai/chatComplete';

beforeEach(() => {
  useCharacterMemory.getState().clearAll();
  useCharacterStore.setState({
    characters: [{ id: 'char-001', name: '小星', description: '', personality: '', scenario: '', systemPrompt: '', postHistoryInstructions: '', messageExamples: '' } as never],
  });
  useXYData.setState({
    conversations: [{ id: 'c-char-001', idolId: 'char-001', characterId: 'char-001', lastMsg: '', lastTime: 0, unread: 0 }],
    messages: [], moments: [], interactions: [],
  });
  useAIConfigStore.setState({
    apiKey: 'sk', model: 'x', provider: 'openai', apiEndpoint: 'e',
    contextWindow: 100_000, maxTokens: 2000, summarizeThreshold: 0,
  } as never);
});

describe('XingYu sendImageMessage → AI reply via session', () => {
  it('image user msg lands in memoryStore as [图片 <url>] + AI reply raw lands as one entry', async () => {
    vi.spyOn(chatCompleteMod, 'chatComplete').mockResolvedValue(
      '[{"type":"text","content":"好可爱的猫"}]',
    );

    useXYData.getState().sendImageMessage('c-char-001', 'https://example.com/cat.jpg');

    await new Promise((r) => setTimeout(r, 2500));

    const mem = useCharacterMemory.getState().getAll('char-001');
    expect(mem).toHaveLength(2);
    expect(mem[0]!).toMatchObject({
      role: 'user',
      speakerId: 'me',
      content: '[图片 https://example.com/cat.jpg]',
    });
    expect(mem[1]!).toMatchObject({
      role: 'assistant',
      speakerId: 'char-001',
      content: '[{"type":"text","content":"好可爱的猫"}]',
    });

    // xingYuDataStore: user image + 1 text bubble from AI
    const msgs = useXYData.getState().messages.filter((m) => !m.streaming);
    expect(msgs).toHaveLength(2);
    expect(msgs[0]!.type).toBe('image');
    expect(msgs[1]!.type).toBe('text');
  });
});
```
