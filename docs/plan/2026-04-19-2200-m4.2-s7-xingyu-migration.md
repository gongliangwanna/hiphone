# M4.2 S7 — XingYu Migration to Tool Registry + Session API

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert XingYu from "hardcoded sticker + signature special types in promptAssembly chunks 7/8" to "registers its own tools + renderer + appSystemPrompt at startup". `scheduleAICharacterReply` switches from direct `chatComplete` to `chatWithCharacter().send`. Legacy `sticker` / `signature` items keep parsing (already supported since S3), and the UI bubble delivery logic (pick the matching sticker, apply signature silently, etc.) stays identical — XingYu's registered tools translate the new `{type:'action', name:'sticker'/'update_signature'}` LLM output into the same UI affordances.

**Architecture:**

```
xingYuRegister.ts (new) — called once from xingYuDataStore on first use:
  registerTools('xingyu', [
    { name: 'sticker',          description, parameters: { stickerId: 'string', content: 'string' } },
    { name: 'update_signature', description, parameters: { text: 'string' } },
  ]);
  registerReplyRenderer('xingyu', defaultXingYuRenderer);  // no-op — default is XingYu already, but explicit confirms ownership
  registerAppSystemPrompt('xingyu', () => {
    const stickers = useStickerStore.getState().packs.flatMap(pack =>
      pack.stickers.map(s => ({ id: s.id, description: s.description })),
    );
    if (stickers.length === 0) return '';
    return '当前可用表情：\n' + stickers.map(s => `${s.id}: ${s.description}`).join('\n');
  });

scheduleAICharacterReply rewrite:
  const session = chatWithCharacter(characterId, { persistent: true });
  // Existing user message already went through _appendMessage (S3 M4.1);
  // session.send with mirror:false to avoid double-counting the user turn.
  const reply = await session.send(userText, { mirror: false });
  // memoryStore assistant entry was NOT written by session (mirror:false) —
  // XingYu still writes it directly here because it has the stale-bubble
  // de-dupe logic; we write `reply.rendered` for consistency.
  useCharacterMemory.getState().append(characterId, {
    role: 'assistant', speakerId: characterId, content: reply.rendered, source: 'xingyu',
  });
  // UI bubble delivery walks reply.items and dispatches:
  //   - action.name === 'sticker'           → bubble with sticker lookup
  //   - action.name === 'update_signature'  → silent updateCharacterSignature
  //   - legacy sticker item                 → unchanged existing dispatch
  //   - legacy signature item               → unchanged existing dispatch
  //   - text                                → bubble
```

Using `mirror: false` avoids double user-message + double assistant entry. The user message already lands via `_appendMessage` (M4.1 S3). The assistant raw output needs the rendered form in memoryStore — we write it ourselves after parsing so bubble delivery stays in sync with memory.

Because XingYu calls `session.send` from outside `withUserAppContext`, the session's captured app id falls back to `'xingyu'` via manual `withUserAppContext` wrap (preferred — matches how XingYu identifies itself) OR we pass `xingyu` through some other channel. We'll wrap the session creation in `withUserAppContext('xingyu', ...)` for clarity.

```typescript
// src/apps/XingYu/xingYuRegister.ts
/**
 * XingYu's AI-integration bootstrap.
 *
 * Registers the app's tools / reply renderer / app-system-prompt under
 * the appId "xingyu". Called once from xingYuDataStore at module import
 * time. Idempotent: multiple invocations are safe (registry Map.set
 * replaces rather than appends).
 *
 * See docs/superpowers/specs/2026-04-19-m4.2-tool-registry-and-rendering-design.md §9
 */

import { registerTools } from '@/platform/ai/toolRegistry';
import { registerReplyRenderer } from '@/platform/ai/replyRendererRegistry';
import { registerAppSystemPrompt } from '@/platform/ai/appSystemPromptRegistry';
import { defaultXingYuRenderer } from '@/platform/ai/defaultXingYuRenderer';
import { useStickerStore } from './stickerStore';

export const XINGYU_APP_ID = 'xingyu';

let registered = false;

export function registerXingYuAi(): void {
  if (registered) return;
  registered = true;

  registerTools(XINGYU_APP_ID, [
    {
      name: 'sticker',
      description: '发一个表情包。stickerId 必须从 [当前任务] 中列出的可用表情里选，不要编造。content 是该表情的简短描述文案，用来让对话上下文仍然能读懂你发了什么表情。',
      parameters: { stickerId: 'string', content: 'string' },
    },
    {
      name: 'update_signature',
      description: '修改自己的个性签名。签名会显示在星球主页上。不要频繁更换，只有在心情或状态明显变化时才调用。',
      parameters: { text: 'string' },
    },
  ]);

  registerReplyRenderer(XINGYU_APP_ID, defaultXingYuRenderer);

  registerAppSystemPrompt(XINGYU_APP_ID, () => {
    const stickers = useStickerStore.getState().packs.flatMap((pack) =>
      pack.stickers.map((s) => ({ id: s.id, description: s.description })),
    );
    if (stickers.length === 0) return '';
    return (
      '当前可用表情：\n' +
      stickers.map((s) => `${s.id}: ${s.description}`).join('\n')
    );
  });
}

/** Test-only: let tests re-run the registration after _resetXxxForTests calls. */
export function _resetXingYuRegistrationForTests(): void {
  registered = false;
}
```

```typescript
  const controller = new AbortController();
  const userText = latestUserMessage?.text ?? '';  // or the existing variable if named differently
  const sessionInstance = withUserAppContext(XINGYU_APP_ID, () =>
    chatWithCharacter(characterId, { persistent: true, signal: controller.signal }),

  aiSessions.set(convId, { session: sessionInstance, controller });

  // We already wrote the user message to memoryStore via _appendMessage in
  // the send* actions below — use mirror:false so session doesn't duplicate.
  // We also write the assistant entry ourselves (rendered form) after
  // bubble delivery, so we can keep XingYu's stale-session abort logic
  // authoritative over the memory write.
  sessionInstance
    .send(userText, { mirror: false })
    .then(async (reply: ChatReply) => {
      // Remove typing indicator placeholder
      const s0 = useXYData.getState();
      useXYData.setState({
        messages: s0.messages.filter((m) => m.id !== placeholderId),

      if (conv.characterId) {

          role: 'assistant',
          speakerId: conv.characterId,

          source: 'xingyu',
        });

      // Deliver bubbles — reply.items contains text / action / legacy sticker / legacy signature
      const active = isChatActive(convId);
      for (let i = 0; i < reply.items.length; i++) {
        if (i > 0) await new Promise((r) => setTimeout(r, 300 + Math.random() * 500));
        if (controller.signal.aborted) return;

        const item = reply.items[i]!;
        const ts = Date.now();
        let msg: Message | null = null;
        let lastMsgPreview = '';

        // Unified action shape — dispatch by action name
        if (item.type === 'action') {
          if (item.name === 'sticker') {
            const stickerId = String(item.params.stickerId ?? '');
            const content = String(item.params.content ?? '');
            const { msg: stickerMsg, preview } = buildStickerBubble({
              convId, senderId, stickerId, content, ts,
            });
            msg = stickerMsg;
            lastMsgPreview = preview;
          } else if (item.name === 'update_signature') {
            if (conv.characterId) {
              useXYData.getState().updateCharacterSignature(
                conv.characterId,
                String(item.params.text ?? ''),
              );
            }
            continue; // silent
          } else {
            // Unknown action — render as plain text fallback so the bubble is informative
            const label = `[${item.name}] ${JSON.stringify(item.params)}`;
            msg = { id: uid(), convId, senderId, type: 'text', text: label, timestamp: ts };
            lastMsgPreview = label.slice(0, 60);
          }
        }
        // Legacy signature (pre-migration model output) — still works
        else if (item.type === 'signature') {
          if (conv.characterId) {
            useXYData.getState().updateCharacterSignature(conv.characterId, item.text);
          }
          continue;
        }
        // Legacy sticker (pre-migration)
        else if (item.type === 'sticker') {
          const { msg: stickerMsg, preview } = buildStickerBubble({
            convId, senderId, stickerId: item.stickerId, content: item.content, ts,
          });
          msg = stickerMsg;
          lastMsgPreview = preview;
        }
        // Text
        else {
          const text = filterReply(item.content) || '[空回复]';
          msg = { id: uid(), convId, senderId, type: 'text', text, timestamp: ts };
          lastMsgPreview = text.slice(0, 60);
        }

        if (!msg) continue;
        const s = useXYData.getState();
        useXYData.setState({
          messages: [...s.messages, msg],
          conversations: s.conversations.map((c) =>
            c.id === convId
              ? {
                  ...c,
                  lastMsg: lastMsgPreview,
                  lastTime: ts,
                  unread: active ? c.unread : c.unread + 1,
                }
              : c,
          ),
        });
      }
    })
    .catch((e) => {
      if (e?.name === 'AbortError' || e?.name === 'AIAbortedError') return;
      const rawMsg = e instanceof Error ? e.message : String(e);
      const brief = rawMsg.length > 80 ? `${rawMsg.slice(0, 80)}…` : rawMsg;

      useXYData.setState({

        ],
        conversations: s.conversations.map((c) =>
          c.id === convId ? { ...c, lastMsg: errText, lastTime: Date.now() } : c,
        ),
      });
    })
    .finally(() => {
      const entry = aiSessions.get(convId);
      if (entry && entry.session === sessionInstance) {
        aiSessions.delete(convId);
      }
```

Add a helper `buildStickerBubble` just above `scheduleAICharacterReply` to dedupe the sticker-lookup logic (used in both action and legacy paths):

```typescript
function buildStickerBubble(args: {
  convId: string;
  senderId: string;
  stickerId: string;
  content: string;
  ts: number;
}): { msg: Message; preview: string } {
  const { convId, senderId, stickerId, content, ts } = args;
  const stickerPacks = useStickerStore.getState().packs;
  let foundSticker: { imageData: string; description: string } | undefined;
  for (const pack of stickerPacks) {
    const s = pack.stickers.find((st) => st.id === stickerId);
    if (s) { foundSticker = s; break; }
  }
  if (foundSticker) {
    return {
      msg: {
        id: uid(),
        convId,
        senderId,
        type: 'sticker',
        stickerUrl: foundSticker.imageData,
        stickerDesc: foundSticker.description,
        timestamp: ts,
      },
      preview: `[表情：${foundSticker.description}]`,
    };
  }
  return {
    msg: {
      id: uid(),
      convId,
      senderId,
      type: 'text',
      text: content || '[表情]',
      timestamp: ts,
    },
    preview: content || '[表情]',
  };
}
```
