# AI 工坊 V1.1 — 草稿历史 + ZIP 导出

**Date:** 2026-04-28
**Branch:** feat/m1-architecture

## 用户需求

> 我希望添加历史记录功能,而不是按 + 号后历史记录就没了; 以及可以导出为 zip 包

当前 `aiAppBuilderStore` 是单草稿模型。"+" 按钮直接清空草稿与对话历史,不可逆。需要支持多草稿并存、随时切回,以及把任一草稿打包成 ZIP 下载到本地。

## UX 设计(对齐 iOS)

### 入口
- NavBar 左侧 **草稿** 按钮(`List` 图标)→ 打开底部 Sheet,列出所有草稿,降序按 `updatedAt`,当前活跃草稿用蓝色高亮。
- NavBar 右侧 **+** 按钮 → 创建空草稿并切换;**不再** `confirm()`,**不**清空原草稿。原草稿保留在列表里。
- NavBar 右侧 **下载** 按钮 → 安装到桌面,行为不变。

### 列表行
模仿翻译 App 的 `RecentRow`(已有左滑删除模式,见 `src/apps/translate/recents/RecentRow.tsx`):
- `motion.div drag="x"` 左滑暴露 **导出 ZIP**(蓝)+ **删除**(红)两个动作。
- 行内容:草稿标题 + 副标题(更新时间 + 文件数)。
- 标题来源:首条 `user` 消息的前 20 字;若空,回退到 `draftId`。

### 删除草稿
- 二次确认 `confirm('确定删除该草稿?')`。
- 若删除的是当前活跃草稿:自动切换到剩余里 `updatedAt` 最大的;若已空,`activeDraftId = null` 回到 EmptyState。

### 导出 ZIP
- 调用 `packDraftZip(id, files)`(已有,在 `builderInstaller.ts`)→ Blob。
- `URL.createObjectURL(blob)` + 创建临时 `<a download="${id}.zip">` 触发浏览器下载。
- 文件名:`<draftId>.zip`(如 `ai-app-tomato-1234.zip`)。

## 架构决策

### 仓库结构
```ts
interface Draft {
  id: string;
  files: Record<string, string>;
  chatHistory: ChatTurn[];
  status: BuilderStatus;
  lastError: string | null;
  createdAt: number;
  updatedAt: number;
  title: string;            // 派生于第一条 user 消息
}

interface AIAppBuilderState {
  drafts: Record<string, Draft>;       // ★ 真实源
  activeDraftId: string | null;        // ★

  // 顶层 mirror — 这些字段是 drafts[activeDraftId] 的镜像。
  // 保留它们是为了不动 builderAgent / builderTools / BuilderChat 等
  // 现有消费者(它们直接 useAIAppBuilderStore((s) => s.draftFiles) 等)。
  draftId: string | null;              // === activeDraftId
  draftFiles: Record<string, string>;
  chatHistory: ChatTurn[];
  status: BuilderStatus;
  lastError: string | null;

  // ── 新增 ──
  createDraft: (firstUserPrompt: string) => string;  // 返回新 id
  setActiveDraft: (id: string) => void;
  deleteDraft: (id: string) => void;
  exportDraftAsZip: (id: string) => Promise<void>;   // 触发浏览器下载
  listDrafts: () => Draft[];                         // updatedAt 降序

  // ── 旧 API,语义保持(写入活跃草稿 + 顶层 mirror) ──
  appendUserMessage / appendAgentMessage / appendToolCall / appendPlanUpdate / appendFinish / setDraftFiles / setStatus / setError
  startNewDraft  // 兼容别名 → createDraft
}
```

### 双写策略
所有 mutator 同时写 `drafts[activeDraftId]` 和顶层 mirror。`setActiveDraft(id)` 拷贝 `drafts[id]` → 顶层。Hydrate 后从 `drafts[activeDraftId]` 重建 mirror。

**为什么不直接让消费者读 `drafts[activeDraftId]`**:消费者面广(builderAgent / builderTools / BuilderChat / AIAppBuilderApp / 测试),零改动是显著的工程价值。

### 持久化
`name` 升级到 `'hiPhone-ai-app-builder-v3'`(v2 仅 dev 用过,丢弃可接受)。partialize 只存 `drafts` + `activeDraftId`,顶层 mirror 在 hydrate 时从 active draft 重建。

### S3 — Export ZIP

- `builderInstaller.ts` 加 `triggerDraftZipDownload(id, files)`:
  ```ts
  export async function triggerDraftZipDownload(id, files) {
    const blob = await packDraftZip(id, files);
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url; a.download = `${id}.zip`;
    document.body.appendChild(a); a.click();
    document.body.removeChild(a);
    URL.revokeObjectURL(url);
  }
  ```
- DraftsSheet 行的"导出"按钮调它
- store.exportDraftAsZip(id) 调它,返回 Promise
