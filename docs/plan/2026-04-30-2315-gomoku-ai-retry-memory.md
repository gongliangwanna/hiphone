# 五子棋 AI 角色对弈第三阶段计划

日期: 2026-04-30 23:15

## 用户需求

AI 角色真实下棋,但如果连续三次不能给出合法落子,降级为本地代码 AI。每一步落子和聊天事件写入角色长期记忆,完整棋盘矩阵不得写入长期记忆。

## 范围

- AI 棋局回合最多语义重试 3 次。
- 解析失败、缺少落子、重复落子、越界、非整数坐标、纯聊天中落子均触发重试。
- 三次失败后调用现有 `getAIMove(board, aiStone)` 降级。
- 降级通过系统气泡透明展示。
- 用户落子、AI 落子、聊天、降级、胜负结果写入角色长期记忆。

## 关键决策

1. 平台 `chatWithCharacter` 已有 JSON 解析重试,本阶段追加五子棋语义重试。
2. 语义重试使用同一会话追加系统纠错提示,避免模型重复犯同一类错误。
3. 五子棋自己写入自然语言事件记忆,`mirror:false` 避免工具原文和棋盘矩阵污染记忆。
4. 降级记忆必须写成“系统代走”,不伪装成角色本人。

## 验证

- 单测覆盖三次非法后本地 AI 降级、合法第二次重试成功、棋盘矩阵不写入记忆、每步事件写入记忆。
