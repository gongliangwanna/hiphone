# 角色标签默认文案女性向

## 用户需求

用户要求把角色编辑里的「标签」默认文案改成女性向。

## 关键决策

1. 标签属于角色基础信息，不属于被移除的角色设定拆分字段，因此保留在编辑页。
2. 只调整标签输入框的占位文案，不改标签存储结构。
3. 默认文案使用女性向角色常见分类：`温柔男友, 年上, 甜宠`。
4. 继续保持上一轮约束：性格、情境、开场白、示例对话不恢复。

## 测试计划

1. 更新角色编辑页测试，确认标签输入框存在且占位文案为女性向。
2. 确认标签编辑仍会写入 `characterStore.tags`。
3. 跑角色编辑页相关测试和 typecheck。
