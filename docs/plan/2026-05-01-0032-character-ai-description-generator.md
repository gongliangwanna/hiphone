# 角色描述 AI 生成

## 用户需求

用户希望在编辑角色时添加 AI 生成功能：用户输入简短描述后，系统帮助丰富角色设定，补充角色外貌、性格、家庭、历史记忆、爱好等内容，成稿大约 800 字。

## 关键决策

1. 功能入口放在「编辑角色」页面内，作为「AI 生成」区块，位于基础信息和最终「角色描述」之间。
2. 用户输入的是生成提示，不直接等同于最终角色描述；生成完成后写入现有 `description` 字段，继续保持单一角色设定字段。
3. 复用现有 `useAIConfigStore`、provider adapter、`chatComplete` 和 `pickGenerationParams`，不新增独立模型配置。
4. prompt 明确要求输出完整角色设定正文，不输出标题、编号、解释或 Markdown；内容覆盖外貌、性格、家庭、历史记忆、爱好、说话方式、关系互动边界，目标约 800 中文字。
5. 缺少 API Key、模型或 endpoint 时在页面内提示错误，不清空已有角色描述。
6. 生成时按钮进入 loading 状态，防止重复提交；生成失败保留用户输入，方便重试。

## 测试计划

1. 新增纯函数测试，验证生成器会用用户输入、角色名、标签、现有描述组装 prompt，并把 AI 返回文本 trim 后返回。
2. 新增错误测试，缺 API Key / 模型时给出明确错误。
3. 扩展角色编辑页测试，验证用户输入提示后点击生成，会调用 AI 并把结果写入 `description`。
4. 跑相关 vitest 和 `pnpm typecheck`。
