# App 图标选图后编辑态计划

## 用户需求

- 进入图标设置页后，选择图片才进入真正的图标编辑页面。
- 编辑页面需要展示 icon 大小。
- 编辑页面继续支持通过手势移动和缩放图片。

## 当前问题

- 当前页面一打开就展示裁剪区域，选图前后没有明显的编辑状态变化。
- 页面没有展示目标图标尺寸或图片体积，用户无法确认保存后的图标规格。
- 移动和缩放逻辑已经存在，但需要和选图后的编辑态绑定，避免用户在未选图时看到可编辑裁剪框。

## 关键决策

- 将图标页拆成两个 UI 状态：当前图标预览态、选图后的裁剪编辑态。
- 选图后展示 `app-icon-editing-panel`，只在这个状态下显示可移动/缩放的裁剪预览和保存按钮。
- 编辑态展示固定输出规格 `512 x 512`、原图尺寸、原图大小、当前缩放比例；保存成功后额外展示压缩后的图标体积。
- 保留原有手势实现：单指/鼠标拖动移动图片，双指 pinch 和滚轮缩放图片。

## 验证

- 更新 Settings 图标编辑单测，覆盖选图后出现编辑面板和尺寸信息。
- 运行 Settings 相关单测。
- 运行 TypeScript 类型检查。
- 需要时用真实浏览器走一次选择图片、移动、缩放、保存流程。
