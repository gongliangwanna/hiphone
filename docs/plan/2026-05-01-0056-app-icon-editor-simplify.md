# App 图标编辑页简化计划

## 用户反馈

- 当前选图后的编辑面板太反直觉。
- 用户只是想编辑图片，不需要展示原图尺寸、文件大小、缩放比例、压缩大小等一堆指标。

## 关键决策

- 移除选图后的指标列表面板。
- 选图后只展示可移动/缩放的裁剪画布、轻量的输出规格 `512 x 512`、更换图片入口和保存按钮。
- 保留压缩保存逻辑，但不在编辑界面展示压缩体积。
- 保留现有手势能力：单指/鼠标拖动移动，双指 pinch 和滚轮缩放。

## 验证

- 更新图标编辑相关单测，确保选图后进入裁剪界面但不出现指标面板。
- 运行 Settings 相关单测。
- 运行 TypeScript 类型检查。
