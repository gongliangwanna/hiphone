# AI 工坊复用全局 API 设置

## 用户需求

- 去掉「设置」里的 AI 工坊专用 API / 模型设置入口。
- AI 工坊生成代码时不再读取单独的工坊配置。
- AI 工坊直接复用现有「AI 设置」中的 API Key、端点、供应商、模型和生成参数，避免用户维护两套配置。

## 关键决策

- 删除设置首页的「工坊代码模型」入口，并从设置导航注册表中移除对应页面。
- AI 工坊的配置解析器只读取 `useAIConfigStore`，不再合并 `aiAppBuilderConfigStore.modelOverride`。
- 保留核心生成流程和错误文案语义：全局 API Key / 模型未配置时仍阻止生成并提示去配置 AI 设置。
- 移除 AI 工坊专用 config store 和它的单测，减少孤立持久化配置继续误导用户。
- 更新 AI 工坊 agent 配置解析单测，覆盖“使用全局 AI 设置”和“缺少配置时失败”的行为。
