# App 图标裁剪可感知性优化计划

## 用户反馈

- 当前图标编辑页虽然能用，但用户很难感知图片可以移动和放大缩小。
- 参考头像上传裁剪，用户需要看到裁剪框，以及裁剪框外仍然可见的图片，才能知道自己在调整哪一块。
- 选图后的 App 名和 `512 x 512` 文案没有意义，需要去掉。
- “更换图片 / 保存图标”操作可以下移，给上方图片编辑区域更多空间。

## 关键决策

- 将选图后的图标预览改为大裁剪舞台：完整图片铺在舞台中，中心显示圆角方形裁剪框，框外区域用半透明遮罩压暗。
- 保留同一套手势逻辑，舞台任意位置都可拖动，双指 pinch 和滚轮缩放继续生效。
- 移除选图后的 App 名和输出尺寸文案，避免干扰裁剪任务。
- 控制区放在裁剪舞台下方，并通过更大的舞台高度把视觉重心留给图片。

## 验证

- 更新图标编辑单测，覆盖选图后出现裁剪舞台、裁剪框和遮罩，且不再展示无意义文案。
- 运行 Settings 相关单测。
- 运行 TypeScript 类型检查。
- 用真实浏览器验证选图、移动、缩放和保存流程。
