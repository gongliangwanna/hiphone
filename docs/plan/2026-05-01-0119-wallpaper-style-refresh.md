# 手机系统壁纸风格刷新计划

## 用户需求

用户希望生成几张新的手机壁纸，用来代替当前默认系统壁纸。壁纸需要覆盖多种风格：

1. 风景：适合桌面与锁屏，主体安静、有空间感。
2. 可爱：亲和、柔和，但不能像儿童贴纸堆满画面。
3. 灵动：有流动感、光感或轻盈动态感，适合 iOS 风格系统背景。
4. 日常：生活化、温暖、适合作为长期默认壁纸。
5. 设计：更偏抽象与现代图形感，可承托图标和毛玻璃层。

## 关键决策

1. 新壁纸作为项目内置系统壁纸，不走用户上传的 `customWallpapers` 数据路径。
2. 使用 5 张 9:16 竖屏位图资产，落到 `public/resource/wallpapers/hiPhone/`，避免引用仅存在于生成目录的图片。
3. 用户反馈首版“没有品位、没有高级感”后，审美方向调整为系统级高级壁纸：克制留白、真实材质、细腻光影、少元素、低噪点，避免插画贴纸感、旅游照片感、普通素材图感。
4. 不删除旧 `public/resource/wallpapers/ios/` 文件，避免历史缓存或用户本地状态引用旧 ID 时出现资源缺失；代码层面只展示新列表。
5. 更新 `systemStore` 默认值和删除自定义壁纸后的 fallback，避免回退到旧 stock ID。
6. 更新 `WallpaperPage` 相关单测，使测试覆盖新的内置壁纸数量、ID 和预览路径。
7. 壁纸画面需要预留图标可读性：避免大面积高对比文字、人物脸部、品牌标识、水印和密集细节。

## 实施阶段

1. 生成并保存 5 张新壁纸资产。
2. 更新内置壁纸列表和系统默认壁纸 ID。
3. 更新壁纸设置页与 store 测试中的旧 ID 断言。
4. 运行相关单测，必要时补齐稳定性检查。
