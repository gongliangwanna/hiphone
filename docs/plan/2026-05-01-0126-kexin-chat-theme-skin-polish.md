# 可爱信聊天主题装扮优化

## 用户需求

上一版本地原型已经能切换自定义气泡，但用户反馈除默认样式外都太丑。随后调研发现，主流聊天 App 的装扮通常不是孤立修改气泡，而是把气泡、聊天背景、输入强调色、时间戳等作为一个主题整体设计。

本轮继续优化：

- 删掉或重做廉价大渐变气泡。
- 保留默认 iOS 蓝色作为基准。
- 将现有 `BubbleSkin` 扩展为更接近聊天主题包的结构。
- 让聊天背景和气泡一起变化，避免“花气泡贴在默认白底上”的廉价感。
- 保留本地图片纹理示例，但改成更克制的低对比纸纹风格。
- 不再自动操作浏览器，由用户自行在本地 URL 验证。

## 关键决策

1. 继续沿用现有文件名 `bubbleSkins.ts`，但语义升级为主题包。
   - 原因：上一版已经接入页面、store、BubbleRenderer，改名会扩大变更面。

2. `Conversation.backgroundUrl` 优先级高于主题背景。
   - 用户给单个聊天设置背景时，应覆盖全局装扮背景。

3. 内置主题改为低饱和、背景联动。
   - 不再使用大面积粉/绿渐变。
   - 主题以“可长期聊天”为标准，不以第一眼花哨为标准。

4. 仍不做 CSS/JS 上传器。
   - 本轮只打磨主题模型和内置审美。
   - 上传器下一阶段基于 `wallpaper + bubble surface + assets` 接入。

## 实施范围

- 扩展 `BubbleSkin`：增加 `chatBackground`、`accentColor`、`timestamp`。
- `ChatDetail` 消息区域应用主题背景。
- `Appearance` 预览区应用主题背景，并更新文案为“聊天主题”。
- 重做内置主题：
  - 默认蓝
  - 雾白
  - 青瓷
  - 白纸便签
  - 夜航
- 调整测试，覆盖本地纹理和主题背景。

## 验收

- 默认蓝保持原样。
- 非默认主题不再是刺眼渐变气泡。
- 切换主题后聊天页背景和气泡一起变化。
- 当前聊天已有自定义背景时，不被全局主题背景覆盖。
- TypeScript 和相关单测通过。
