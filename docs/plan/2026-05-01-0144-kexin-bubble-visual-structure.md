# 可爱信气泡结构化视觉优化

## 用户需求

用户反馈：当前内置气泡看起来差异不大，主要像换颜色。需要让气泡装扮真正体现“重绘气泡”，但不能修改聊天背景，因为聊天背景已有独立自定义能力。

## 关键决策

1. 不改聊天背景。
   - 气泡装扮只影响文本气泡内部和边界。

2. 给 `BubbleSkinSurface` 增加受控装饰层。
   - 不开放任意 DOM。
   - 内置装饰由 `BubbleRenderer` 根据 `decoration` 渲染。
   - 后续用户上传 CSS/图片时，也可以映射到这些受控装饰能力。

3. 内置气泡不再只靠颜色区分。
   - 雾白：玻璃高光/内描边。
   - 青瓷：瓷器描边/角线。
   - 白纸便签：纸纹 + 顶部胶带。
   - 夜航：深色卡片 + 金色侧线/星点。
   - 默认蓝保持不变。

4. 装饰层必须不影响文本选择、长按菜单和消息内容。
   - 装饰元素 `pointerEvents: none`。
   - 内容层保持在 `zIndex: 1`。

## 验收

- 切换内置气泡后能看到形态/材质差异，而不是只换颜色。
- 本地图片纹理仍只作用于气泡。
- 聊天背景不变。
- 相关单测和 TypeScript 检查通过。
