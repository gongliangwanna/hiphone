# 在场 App 回退参考稿改动计划

## 用户需求

用户反馈“感觉还没有，改回去”，即撤回上一轮按参考设计稿收敛的 UI 改动，回到上一版在场 App 视觉改造后的状态。

## 回退范围

1. 回退首页：恢复上一版带场景预览卡、头像选择器、场景输入、预设场景、进入按钮和记录入口的视觉。
2. 回退场景页：恢复上一版沉浸式头图、叙事流卡片和底部玻璃输入栏。
3. 回退离开 Sheet：恢复上一版总结展示逻辑，短内容未生成总结时显示短提示，不强制展示四项“未生成”。
4. 回退记录列表和记录详情：恢复上一版影像记录卡和只读详情结构。
5. 删除上一轮为参考稿添加的测试断言和计划文档，不动核心 AI、记忆、记录持久化逻辑。

## 验证

1. `pnpm vitest run src/apps/Presence`
2. `pnpm exec tsc --noEmit --pretty false`
3. `pnpm build`
