# 在场角色卡选中边缘裁切修复计划

## 用户需求

选择角色卡片在选中状态下，上边缘没有完整显示出来，被父容器裁掉，需要修复。

## 根因判断

角色卡选中态会执行 `y: -2` 和 `scale: 1.03`，但横向滚动容器只有底部 padding，没有顶部安全空间。因为容器使用 `overflow-x-auto`，卡片向上移动和放大后的上边缘会被滚动容器裁切。

## 关键决策

1. 不改角色卡整体风格和选中动效，只给横向滚动容器补充顶部空间。
2. 增加测试，约束角色选择器滚动容器必须保留顶部 padding，避免后续改 UI 时再次裁切选中态。
3. 验证通过单测、类型检查、构建和浏览器截图。

## 验证

1. `pnpm vitest run src/apps/Presence`
2. `pnpm exec tsc --noEmit --pretty false`
3. `pnpm build`
4. 浏览器截图检查选中角色卡上边缘完整显示。
