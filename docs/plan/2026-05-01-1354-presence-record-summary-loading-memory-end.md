# 在场记录总结、Loading 和记忆结束提示计划

## 用户需求

1. 去掉在场记录中的“待办事项/待续事项”。
2. 生成记录时增加 loading 动画，让玩家知道正在生成中。
3. 写入 AI 记忆的内容末尾需要明确告诉 AI：该场景已结束，切回到线上模式。

## 关键决策

1. 将 `PresenceSummary` 从四项改为三项：`场景`、`发生了什么`、`情绪变化`。
2. 总结 prompt 和解析器不再要求或解析 `待续事项`；旧记录里即使残留该字段，也不再展示。
3. 离开场景 Sheet 在 `loading` 时显示旋转图标和“正在生成在场记录…”文案。
4. 记忆写入内容末尾追加固定系统提示：`该场景已结束，切回到线上模式。`

## 验证

1. `pnpm vitest run src/apps/Presence`
2. `pnpm exec tsc --noEmit --pretty false`
3. `pnpm build`
4. 浏览器截图检查离开场景时的 loading 动画。
