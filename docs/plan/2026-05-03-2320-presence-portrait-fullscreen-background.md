# 在场竖屏全屏背景计划

## 用户需求

用户在「在场 app」场景页中看到当前背景只出现在顶部横幅区域，下方叙事内容区域仍是浅色底，沉浸感不足。希望将场景背景改为竖屏全屏背景，让背景贯穿整个场景页。用户还要求使用 image gen 生成一张预览图，用来确认更沉浸的方向。

## 范围

1. 只调整「在场 app」进行中的场景页，不改变首页、记录列表、记录详情页的阅读规则。
2. 不引入聊天气泡，不展示场景笔记，继续遵守 `src/apps/Presence/AGENTS.md`。
3. 保留 iOS Shell 的导航栏和底部输入栏范式，场景内容在全屏背景上方以毛玻璃/半透明层呈现。
4. 增加测试，确保场景页拥有全屏背景层，并确保内容层位于背景层上方。

## 关键决策

1. 在 `PresenceApp` 的 scene view 内新增全屏背景层，使用当前 session 的 `backdropId` 取图，`object-cover` 填满整个可见场景区域。
2. `SceneHero` 改为不再承载顶部横幅图片，而是作为叠加在全屏背景上的角色与场景说明卡片；这样避免顶部图片和全屏图片重复渲染，也更贴近沉浸式竖屏场景。
3. 叙事内容区域保持可滚动，但背景不随内容滚动；通过半透明渐变和毛玻璃卡片保证文字可读。
4. 底部输入栏使用半透明 chrome 材质，维持 iOS 风格，不改动交互逻辑。
5. image gen 预览图只作为视觉预览，不作为本次代码依赖资源，避免把预览资产绑定到当前实现。

## 验证

1. 先为 `PresenceApp` 增加场景页全屏背景的失败测试。
2. 实现后运行对应 Presence 测试。
3. 运行构建或类型检查，确认 TS/React 结构没有破坏。
