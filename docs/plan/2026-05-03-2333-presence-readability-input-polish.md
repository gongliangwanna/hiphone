# 在场发言可读性与输入框样式计划

## 用户需求

用户反馈「在场 app」全屏背景改造后，角色说话内容完全看不清；同时希望人物说话和非说话的格式有区分；底部输入框希望按刚生成的预览图样式调整。

## 范围

1. 只调整进行中场景页的互动流和底部输入栏。
2. 不改变首页、记录列表、记录详情只读逻辑。
3. 不引入聊天气泡，不展示场景笔记；仍保持自由小说式文本。
4. 继续使用 iOS 风格毛玻璃、圆角、蓝色发送按钮。

## 关键决策

1. 角色回复卡片提高到接近不透明的玻璃白底，并增加阴影和 blur，避免被竖屏背景吞掉。
2. `FragmentStream` 对角色回复逐行分类：
   - 括号动作/舞台指示：灰色斜体小字；
   - 引号包裹的台词：独立高对比台词块；
   - 普通叙事：正常正文段落。
3. 用户输入/动作不再直接浮在背景上，改成紧凑的浅色动作条，与角色回复区分。
4. 底部输入栏改成预览图方向：浮动深色玻璃托盘、内嵌半透明输入胶囊、右侧蓝色发送圆钮。
5. 先补单测验证格式区分和输入托盘结构，再改实现。

## 验证

1. 新增/调整 `PresenceApp` 和 `FragmentStream` 相关测试。
2. 运行 `npm test -- src/apps/Presence`。
3. 运行 `npm run typecheck` 和 `npm run build`。
4. 用 Playwright 截图检查竖屏场景的文字可读性和输入栏外观。
