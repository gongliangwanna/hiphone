# 在场小说沉浸感改版计划

## 用户需求

用户反馈当前「在场 app」场景页仍然太丑，没有看小说的沉浸感。截图中的主要问题是：顶部白色导航和大块角色卡割裂背景；正文像聊天消息卡片而不是小说正文；蓝色台词块和用户气泡过于工具化；底部输入托盘太重，抢阅读注意力。

## 范围

1. 只改进行中场景页的视觉层级，不改变场景创建、发送、离开、保存记录逻辑。
2. 继续使用 `system/NavBar`，但给 NavBar 增加暗色玻璃外观供沉浸式页面使用。
3. `FragmentStream` 从“多条消息卡”改成“连续小说阅读层”。
4. 人物说话、叙事、动作仍有区分，但通过小说排版区分，不再用强蓝色块。
5. 保留底部输入能力，但视觉上降低重量。

## 关键决策

1. 场景页进入时使用暗色状态栏与暗色玻璃导航栏，避免顶部白条破坏沉浸感。
2. 顶部角色卡改成低存在感的场景信息条：小头像、角色名、短场景描述，不再像聊天资料卡。
3. 有互动内容时使用一整块暖色半透明阅读纸张；用户输入显示为小号「你：内容」，角色回复合并进正文。
4. 角色台词使用小说式加粗/缩进/前导破折号的排版；动作使用斜体灰字；叙事使用正常正文。
5. 底部输入区保持浮动，但降低黑色遮罩厚重感，避免像工具栏压住阅读内容。

## 验证

1. 更新 `FragmentStream` 测试，锁定阅读层、用户行、叙事、台词、动作的结构。
2. 更新 `PresenceApp` 测试，锁定场景页使用暗色 NavBar 与输入托盘结构。
3. 跑 `npm test -- src/apps/Presence`、`npm run typecheck`、`npm run build`。
4. 用 Playwright 截图确认页面更接近小说阅读体验。
