# 在场玩家与角色台词样式修正计划

## 用户需求

用户反馈小说沉浸版中玩家说的话太不显眼；角色说话不应该加横杠，改为加粗并带冒号即可。当前 `— ......小星星。` 的前导横杠会让语义不清。

## 范围

1. 只调整 `FragmentStream` 的玩家行和角色台词行格式。
2. 保留连续小说阅读纸张、叙事正文、动作斜体的方向。
3. 角色台词需要显示为 `角色名：台词`，并加粗。
4. 玩家输入需要比当前小灰字更醒目，但仍不能回到聊天气泡风格。

## 关键决策

1. `FragmentStream` 新增可选 `characterName`，场景页和记录详情传入当前角色名。
2. 角色台词去掉前导横杠，渲染为加粗 `史塔克：......小星星。`。
3. 玩家行渲染为更醒目的「你：hi」阅读标记：深一点的文字、浅色底、左边细蓝线。
4. 测试先锁定台词内容不含横杠，并包含角色名冒号。

## 验证

1. 更新 `FragmentStream.test.tsx`。
2. 运行 `npm test -- src/apps/Presence src/system/NavBar/NavBar.test.tsx`。
3. 运行 `npm run typecheck` 和 `npm run build`。
4. 用 Playwright 截图确认玩家行和角色台词格式。
