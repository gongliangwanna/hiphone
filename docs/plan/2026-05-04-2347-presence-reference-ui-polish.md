# 在场参考图 UI 优化计划

## 用户需求

用户希望按参考图继续优化「在场 app」场景页 UI。参考图的核心方向是更像沉浸式夜读小说页：玩家发言为右侧蓝紫气泡，角色正文为暖色半透明阅读纸张，角色信息卡带夜晚氛围装饰，底部输入区更轻，不再像一整块工具托盘。

## 范围

1. 只调整进行中场景页的视觉层级和 `FragmentStream` / `SceneHero` / 输入区样式。
2. 不改变发送、离开、总结、保存记录逻辑。
3. 保留玩家发言和角色正文分卡。
4. 保留角色台词 `角色名：台词` 格式。

## 关键决策

1. 玩家发言改为右侧蓝紫渐变气泡，并显示 turn 时间。
2. 角色阅读卡降低实白感，改为暖色半透明纸张，保留高可读正文。
3. 角色卡右侧增加月亮/星光氛围图层，强化夜间图书馆故事感。
4. 输入区去掉厚重整块深色背景，只保留浮动输入胶囊和蓝色发送按钮。
5. 用测试锁定可验证结构：右侧玩家气泡、时间、角色卡氛围层、轻量输入区。

## 验证

1. 更新 `FragmentStream.test.tsx`、`SceneHero` 测试和 `PresenceApp` 测试。
2. 先观察失败，再实现。
3. 运行 `npm test -- src/apps/Presence src/system/NavBar/NavBar.test.tsx`。
4. 运行 `npm run typecheck` 和 `npm run build`。
5. Playwright 截图复核视觉。
