# 五子棋新局抽屉移动端开始按钮修复计划

日期: 2026-05-05 00:13

## 用户需求

用户在手机上打开五子棋 App 后,点击右上角加号会弹出下方新局抽屉。当前抽屉底部的「开始」按钮在手机视口下不明显或不可见,导致用户难以启动新局。需要让「开始」按钮在手机尺寸下稳定可见、易点击,同时保持现有 iOS 风格的底部抽屉体验。

## 根因判断

`NewGameSheet` 的面板设置了 `max-h-[78%]` 和 `overflow-hidden`,但内部没有使用纵向 flex 布局来约束滚动区域。「开始」按钮位于同一个滚动内容块末尾,当角色列表和先手选项高度超过面板最大高度时,按钮会进入被裁剪的区域。

## 关键决策

1. 不改变五子棋业务逻辑、角色选择逻辑、AI 先手逻辑。
2. 将抽屉面板改为纵向 flex 布局: 顶部标题固定,中间角色和先手选项滚动,底部「开始」按钮固定在 footer 中。
3. footer 使用 `var(--app-safe-bottom)` 留出 iOS 底部安全区,避免按钮贴近 Home Indicator。
4. 保持现有色彩、圆角、字号和 iOS 风格,只做移动端可用性修复。
5. 先写布局回归测试,覆盖「开始」按钮不应被放进可滚动列表末尾这一约束。

## 交付清单

- 更新 `src/apps/Gomoku/NewGameSheet.tsx` 的抽屉布局。
- 更新 `src/apps/Gomoku/__tests__/GomokuApp.test.tsx` 增加移动端新局抽屉按钮布局回归测试。

## 测试计划

1. 先运行新增测试,确认当前实现失败。
2. 修复组件后运行 `npm test -- src/apps/Gomoku/__tests__/GomokuApp.test.tsx`。
3. 运行 `npm run typecheck` 确认类型无回归。
