## 用户需求

用户要求把心跳前置叙事统一命名为“经历”。上下文和文案都需要同步修改。

## 关键决策

1. 记忆块标签统一使用 `[经历]` / `[经历结束]`。
2. 设置页开关文案使用“经历”，副文案保留“心跳前生成隐藏经历记忆”。
3. LLM prompt 仍然保留“小手机外的生活”语义约束，但不再使用旧功能名。
4. 代码内部函数名和配置字段先不大规模重命名，避免扩大迁移面；本次聚焦用户可见文案、LLM 上下文、记忆标签和测试断言。
5. 兼容旧记忆：读取上一段经历时同时识别旧标签和新标签，避免已写入记忆断档。

## 执行步骤

2. 运行相关测试观察失败。
3. 修改实现：`heartbeatVirtualWorldStory` 写入新标签，`buildMemoryEntry` 将旧标签归一化为新标签，`AGENTS/CLAUDE` 文档改名。
4. 运行聚焦测试和 typecheck。
